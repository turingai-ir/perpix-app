# Studio در اپ کاربر — فازبندی (موبایل‌اول)

**دامنهٔ محصول (تصمیم مالک):** کاربر ویدیو می‌آورد، **زیرنویس می‌سازد، کات می‌کند و کلیپ‌ها را به هم می‌چسباند**، ظاهر کپشن را انتخاب می‌کند و خروجی MP4 می‌گیرد. سقف خروجی **۱۰۰MB** می‌ماند.
بقیهٔ امکانات (افکت، موسیقی، متن آزاد، حذف پس‌زمینه، …) در این مرحله نیستند.

**اصل:** طراحی از موبایل شروع می‌شود و حس اپ موبایل دارد. دسکتاپ هم پشتیبانی می‌شود، ولی چیدمان وب ساخته نمی‌شود: همان رابط موبایل در یک ستون باریک وسط صفحه می‌نشیند و فقط کنترل‌ها برای ماوس و کیبورد هم کار می‌کنند.

## ساختار کد (`apps/app`)
```
src/features/studio/        همه‌چیز Studio، جدا از بقیهٔ اپ
  shell/      پوسته: تمام‌صفحه، safe-area، تب‌بار پایین، انتقال بین صفحه‌ها
  ui/         اجزای موبایلی: BottomSheet، SegmentedControl، ...
  projects/   خانه و فهرست پروژه‌ها
  import/     انتخاب/آپلود ویدیو و ساخت زیرنویس
  editor/     پلیر، تایم‌لاین (کات و چسباندن)، ویرایش کلمه‌ها
  styles/     گالری قالب‌ها و تنظیم سریع ظاهر
  export/     رندر و خروجی
src/pages/studio/           فقط route ها
```
مسیرها: `/studio`، `/studio/:projectUuid`، `/studio/:projectUuid/export`. این مسیرها بیرون `AppLayout` هستند (مثل `/editor`) و `requireSession` دارند.

## قواعد حس موبایل
- `100dvh`، بدون اسکرول صفحه؛ فقط داخل ناحیه‌های مشخص اسکرول می‌شود.
- `env(safe-area-inset-*)` برای ناچ و نوار پایین.
- تب‌بار پایین فقط در صفحهٔ خانه؛ ویرایشگر تمام‌صفحه است.
- تنظیمات در bottom sheet (vaul) با drag، نه دیالوگ.
- هدف لمسی حداقل ۴۴ پیکسل، کنترل‌های اصلی در ناحیهٔ شست.
- `prefers-reduced-motion` رعایت می‌شود.
- RTL و فارسی پیش‌فرض است؛ متن‌ها در `fa.json`.

## فازها

| فاز | هدف | خروجی قابل‌دیدن |
|---|---|---|
| ۰. پایه | پوسته، route ها، BottomSheet، i18n، `api.ts` بازتولیدشده | `/studio` یک پوستهٔ اپ‌مانند خالی نشان می‌دهد |
| ۱. پروژه‌ها | فهرست، ساخت، تغییر نام، حذف، حالت خالی | خانهٔ Studio با کارت پروژه‌ها |
| ۲. ورود و زیرنویس | انتخاب ویدیو (گالری/دوربین/فایل‌های من)، آپلود، ساخت زیرنویس برای هر فایل، polling، هشدار عمر ۷روزه | از ویدیو به زیرنویس آماده |
| ۳. ویرایشگر | پلیر با کپشن زنده، تایم‌لاین، **کات** (جدا کردن، بریدن ابتدا/انتها، حذف)، **چسباندن** چند کلیپ و جابه‌جایی ترتیب، ویرایش متن کلمه‌ها، ذخیرهٔ خودکار با `revision` | هستهٔ محصول |
| ۴. ظاهر | گالری قالب‌ها (ادمین و خودم)، تنظیم سریع، ذخیره به‌عنوان قالب من | ظاهر کپشن عوض می‌شود |
| ۵. خروجی | بررسی توان مرورگر، رندر با WebCodecs و Mediabunny، پیشرفت، رعایت ۱۰۰MB با کاهش بیت‌ریت، Share/Save | فایل MP4 |
| ۶. صیقل | PWA، پیش‌نویس آفلاین، کارایی، Safari/Firefox، دسترس‌پذیری، تست‌ها | آمادهٔ انتشار |

فاز ۵ می‌تواند موازی با ۴ پیش برود. انتخاب هوشمند کلمهٔ کلیدی با مدل بعد از فاز ۳ بررسی می‌شود.

## نکته‌های طراحی
- **هزینه:** فقط ساخت زیرنویس را Gateway می‌گیرد؛ بقیهٔ Studio (پروژه، قالب، کات، چسباندن، خروجی) رایگان است. هزینه برای کل فایل است، نه بخش نگه‌داشته‌شده؛ پس UI پیش از ساخت زیرنویس باید روشن بگوید چه می‌شود.
- **کات روی `document`:** کات و ترتیب کلیپ‌ها فقط در `document` پروژه ذخیره می‌شوند (بک‌اند آن را تفسیر نمی‌کند). زمان کلمه‌ها در رندر با نگاشت «زمان فایل ← زمان خروجی» حساب می‌شود؛ زیرنویس خام تغییر نمی‌کند.
- **عمر محتوا:** فایل، پروژه و transcript پس از ۷ روز پاک می‌شوند؛ UI باید زمان باقی‌مانده را نشان دهد.
- **تعارض ذخیره:** `PUT` با `revision`؛ خطای `1903` یعنی نسخهٔ جدیدتری هست.
