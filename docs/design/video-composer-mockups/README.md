# طرح‌های پیشنهادی فرم ساخت ویدیو

این دو تصویر برای تصمیم‌گیری دربارهٔ تجربهٔ کاربری هستند، نه مشخصات نهایی API. ترتیب پنل‌ها در هر تصویر از چپ به راست است.

| تصویر | مدل‌ها |
| --- | --- |
| `seedance25-kling-veo-aleph.png` | Seedance 2.5، Kling 3.0 Standard، Veo 3.1 Fast، Aleph 2.0 |
| `grok-gemini-seedance20.png` | Grok Imagine Video، Grok Imagine Video 1.5، Gemini Omni Flash، Seedance 2.0 |

زبان بصری از صفحهٔ فعلی PerPix گرفته شده است: پس‌زمینهٔ نزدیک به مشکی، کارت‌های تیره، حاشیهٔ ظریف و تأکید بنفش و فیروزه‌ای. الگوی مشترک شامل انتخاب مدل، انتخاب هدف کاربر، رسانه، پرامپت، تنظیمات و دکمهٔ تولید است. بخش رسانه و انتخاب هدف برای هر مدل تغییر می‌کند؛ Aleph تب حالت ندارد.

پیوست اولیه هشت مدل را نام می‌برد، در حالی که درخواست فعلی هفت مدل است. تا تعیین مدل حذف‌شده، هر هشت مورد نمایش داده شده‌اند. نام حالت‌ها، محدودیت‌ها و کنترل‌های هر تصویر باید پیش از پیاده‌سازی با `config_schema` زندهٔ همان مدل تطبیق داده شوند؛ نمونه‌های پرامپت و تصاویر رسانه‌ای صرفاً نمایشی‌اند.
