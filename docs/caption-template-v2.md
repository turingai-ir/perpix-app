# قرارداد قالب کپشن، نسخهٔ ۲

پیش‌زمینه و تحقیق: [caption-research.md](./caption-research.md).
این سند قراردادی است که ادمین (ویرایشگر)، اپ کاربر (استودیو و صدور) و بسته‌ی مشترک `@perpix/caption-renderer` با آن کار می‌کنند.
بک‌اند فقط آن را نگه می‌دارد (`config` در `caption_presets`) و هیچ‌وقت تفسیرش نمی‌کند.

## ۱. اصول

1. **قالب داده است، نه کد.** هیچ CSS یا JS دلخواهی پذیرفته نمی‌شود، پس امن است و هر فریم قابل‌پیش‌بینی.
2. **تابع خالص زمان.** `render(t)` فقط از قالب، کلمه‌ها، اندازهٔ قاب و `t` تصویر می‌سازد. جابه‌جایی روی نوار، پخش و صدور فریم‌به‌فریم یک تصویر می‌دهند.
3. **تنوع از ترکیب می‌آید.** نقش‌ها × حالت‌ها × انیماتورها × دکوراسیون‌ها، نه کد جدا برای هر قالب.
4. **هیچ خطایی از ورودی بد.** `normalizeTemplate` هر چیز ناقص، نامعتبر یا ناشناخته را به پیش‌فرض برمی‌گرداند.
5. **تصادفی با seed.** هر تصادف تابع `(seed, شمارهٔ کلمه)` است، نه `Math.random()`.
6. **فارسی اول.** انیمیشن در سطح کلمه یا بالاتر است. حرف‌به‌حرف ممنوع چون حروف چسبیده را می‌شکند.

## ۲. ساختار

```jsonc
{
  "version": 2,
  "base":   { "font": {...}, "text": {...}, "fill": {...}, "stroke": {...}, "shadow": {...} },
  "layout": { "anchor": "bottom", "offset": 0.12, "maxWidth": 0.86, "wordsPerPage": 4,
              "pauseMs": 700, "safeZone": "none" },
  "box":    { "enabled": false, ... },
  "states": { "upcoming": {...}, "active": {...}, "spoken": {...} },
  "roles":  { "key": {...}, "accent": {...} },
  "roleRules": [ { "role": "key", "when": "longest" } ],
  "animators":   [ ... ],
  "decorations": [ ... ],
  "emoji":  { "enabled": true, "size": 0.9 }
}
```

### ۲.۱ سبک پایه (`base`)
- `font`: `family`، `size` (برای قاب ۱۰۸۰ پیکسلی، با مقیاس خودکار)، `weight` (۱۰۰ تا ۹۰۰)، `italic`.
- `text`: `uppercase`، `align` (center، left، right)، `lineHeight`، `letterSpacing` (برای فارسی نادیده گرفته می‌شود).
- `fill`: `color`، و `gradient` اختیاری `{ from, to }` از بالا به پایین کلمه.
- `stroke`: `width`، `color`.
- `shadow`: `enabled`، `color`، `blur`، `offsetX`، `offsetY`، `opacity`. سایه با جابه‌جایی صفر همان **glow** است.

### ۲.۲ چیدمان (`layout`)
- `anchor`: top، middle، bottom. `offset`: فاصله از لبه، کسری از ارتفاع قاب.
- `maxWidth`: بیشترین پهنای خط، کسری از پهنای قاب.
- `wordsPerPage`: ۱ تا ۱۲. `pauseMs`: مکثی که صفحه را می‌شکند (۲۰۰ تا ۲۰۰۰).
- `safeZone`: `none` یا `reels`. در `reels` بلوک کپشن داخل منطقهٔ امن شبکه‌های اجتماعی می‌ماند: ۱۴٪ بالا، ۳۵٪ پایین و ۶٪ هر کنار آزاد (از [Overlap](https://overlap.ai/blogs/how-to-add-captions-to-clips)، اعداد برای قاب ۹:۱۶ و فقط راهنما).

### ۲.۳ حالت‌ها (`states`)
حالت هر کلمه نسبت به زمان: `upcoming` (هنوز گفته نشده)، `active` (در حال گفتن)، `spoken` (گفته شد).
هر حالت یک وصلهٔ استایل است: `color`، `opacity`، `scale`، `strokeColor`.
حالت‌ها وزن، قلم و اندازه را عوض نمی‌کنند تا چیدمان خط با زمان جابه‌جا نشود.

### ۲.۴ نقش‌ها (`roles`)
نقش پایه `normal` است (همان `base`). تا ۷ نقش دیگر با نام دلخواه (`key`، `accent`، …).
وصلهٔ هر نقش: `color`، `scale`، `weight`، `italic`، `family`، `uppercase`، `strokeColor`، `strokeWidth`.
نقش‌ها اندازهٔ کلمه را عوض می‌کنند و در چیدمان اثر دارند.

**قاعدهٔ نقش‌دهی (`roleRules`)**، به ترتیب، اولین که منطبق شد:
1. `word.role` که دستی یا مدل در رونویسی گذاشته.
2. `word.emphasis: true` برابر نقش `key`.
3. `roleRules[i]`: `when` یکی از `number` (کلمه‌ای با رقم)، `longest` (بلندترین کلمهٔ صفحه)، `last` (آخرین کلمهٔ صفحه).

### ۲.۵ انیماتورها (`animators`، حداکثر ۲۴)
```jsonc
{
  "select":   { "scope": "word", "roles": ["key"], "states": ["active"], "position": "any" },
  "trigger":  "enter",            // enter | exit | active | loop
  "from":     "page",             // page | word  (enter: ساعت شروع از صفحه یا از کلمه)
  "durationMs": 220, "delayMs": 0, "staggerMs": 60,
  "ease": "back.out",
  "props": { "opacity": [0, 1], "scale": [0.6, 1], "x": [0, 0], "y": [0.3, 0], "rotate": [-6, 0] },
  "jitter": { "rotate": 4, "x": 0, "y": 0, "scale": 0 },
  "seed": 7,
  "after": "revert",              // active: revert | keep
  "periodMs": 1200                // loop
}
```
- `scope`: `page` (کل بلوک)، `line` (هر خط)، `word`، `char` (هر حرف، فقط لاتین؛ کلمهٔ فارسی کل کلمه را یک «حرف» حساب می‌کند تا حروف چسبیده نشکنند). جلوهٔ wipe روی کلمه‌ای که حروفش جدا حرکت می‌کنند اعمال نمی‌شود.
- **انتخابگر:** `roles` (خالی یعنی همه)، `states` (فقط برای `word`)، `position`: `any`، `first`، `last`، `odd`، `even` (نسبت به شمارهٔ واحد در صفحه).
- `props`: هر کدام `[از, به]`:
  - ضرب‌شونده: `opacity`، `scale`، `scaleX`، `scaleY` (چرخش ورقی با `scaleX` از ۰)، `reveal` (آشکار شدن کلمه از ابتدا، فقط برای کلمه).
  - جمع‌شونده: `x`، `y` (کسری از اندازهٔ قلم)، `rotate` و `skewX` (درجه)، `blur` (پیکسل)، `glow`.
  - `tint` (۰ تا ۱): ترکیب رنگ متن با رنگ `tint` انیماتور؛ همان رنگ، رنگ `glow` هم هست.
- **`enter`:** از `from` به `to` در `durationMs`، شروع از `delayMs + شمارهٔ واحد × staggerMs` پس از شروع صفحه (یا شروع کلمه با `from: "word"`). پیش از شروع مقدار `from` نگه داشته می‌شود.
- **`exit`:** در `durationMs` پایان صفحه از `from` به `to`. واحدهای اول زودتر می‌روند (stagger).
- **`active`:** وقتی کلمه گفته می‌شود از `from` به `to`. پس از پایان کلمه یا به حالت عادی برمی‌گردد (`revert`) یا می‌ماند (`keep`).
- **`loop`:** رفت‌وبرگشت نرم بین `from` و `to` با دورهٔ `periodMs`؛ فاز هر واحد با `staggerMs` جابه‌جا می‌شود (موج).
- **`jitter`:** مقداری ثابت و تصادفی (با `seed` و شمارهٔ کلمه) که تا وقتی انیماتور فعال است روی کلمه می‌ماند. برای حس «دست‌ساز» مثل چرخش تصادفی کلمه‌ها.
- **easing:** فقط از فهرست `linear`، `power2.out`، `power3.out`، `power2.inOut`، `back.out`، `bounce.out`، `elastic.out`، `expo.out`، `sine.inOut`.

### ۲.۶ دکوراسیون‌ها (`decorations`، حداکثر ۸)
چیزی که پشت یا روی کلمه کشیده می‌شود:
- `kind`: `pill` (قرص پشت کلمه)، `underline` (زیرخط)، `marker` (ماژیک روی نیمهٔ پایین)، `wipe` (پر شدن رنگ، کاراوکه).
- `select`: `roles` و `states` مثل بالا (مثلاً `states: ["active"]`، یا `["active", "spoken"]` برای ماندن).
- `color`، `size` (ضخامت زیرخط یا ماژیک، یا فاصلهٔ قرص)، `radius`.
- `reveal`: `fade` یا `sweep` (از ابتدای کلمه، راست‌به‌چپ در فارسی). `wipe` همیشه `sweep` و با طول کلمه همگام است.

### ۲.۷ ایموجی (`emoji`)
کلمه‌ای که `word.emoji` دارد بالای خودش ایموجی می‌گیرد. `size` ضریب اندازهٔ قلم.

### ۲.۸ انیماتورهای آماده
`ANIMATOR_PRESETS` (۲۰ عدد) با یک کلیک به قالب اضافه می‌شوند: محو، pop، زوم ضربه‌ای، ظاهر شدن از محو (blur)، لغزیدن از کنار، کج وارد شدن، شناور ماندن، افتادن و چرخش کلمه‌ها، آشکار شدن کلمه، کج و تصادفی، کش آمدن (rubber)، چشمک رنگی، درخشش ضربانی، لرزش، و چهار حالت حرف‌به‌حرف برای لاتین (تایپ، جهش، موج، بزرگ شدن).

## ۳. قالب‌های مرجع
در `references.ts`: `classic`، `karaoke`، `hormozi`، `mrbeast`، `ali`، `two_word_pop`، `word_by_word`، `boxed`، `key_words`، `marker`، `wave`، `neon`، `typewriter`، `blur_rise`، `glitch`، `flip_words`، `letter_bounce`، `rubber_pop`.
هرکدام فقط تفاوتشان با پیش‌فرض را می‌گویند و ادمین از روی آن‌ها شروع می‌کند.

## ۴. مهاجرت از نسخهٔ ۱
`normalizeTemplate(raw)`: اگر `raw.version === 2` باشد نرمال می‌شود. در غیر این‌صورت به‌عنوان نسخهٔ ۱ خوانده، با `migrate.ts` به ۲ تبدیل و نرمال می‌شود.
قالب‌های ذخیره‌شده با `schema_version: 1` بی‌تغییر کار می‌کنند و ادمین هنگام ذخیرهٔ بعدی نسخهٔ ۲ می‌نویسد (`schema_version: 2`).

## ۵. ویرایشگر ادمین
- پیش‌نمایش زنده، پخش و نوار زمان، قاب ۹:۱۶ و ۱۶:۹، متن نمونهٔ فارسی و انگلیسی، پس‌زمینهٔ تیره و روشن.
- **شروع از قالب مرجع.**
- بخش‌ها: سبک پایه، چیدمان، جعبه، حالت‌ها، نقش‌ها و قاعده‌ها، انیماتورها (فهرست قابل‌افزودن/حذف/کپی)، دکوراسیون‌ها، ایموجی.
- **پیش‌نمایش ایمن:** هر تغییر فوری اعمال می‌شود. JSON پیشرفته برای مهندسین.
- اعتبارسنجی حجم: ≤ ۶۴ کیلوبایت، همان سقف بک‌اند.

## ۶. آزمون
- واحد (Vitest در بسته): نرمال‌سازی و مهاجرت، قواعد نقش، انتخابگر، ارزیابی هر `trigger` و `jitter` با seed ثابت، صفحه‌بندی.
- شناخت پایدار: نمونهٔ `render(t)` برای چند زمان باید با نتیجهٔ ارزیابی خالص همخوان باشد.
- بصری (دستی): هر قالب مرجع در فارسی و انگلیسی، ۹:۱۶ و ۱۶:۹.

## ۷. چه چیزی بعداً می‌آید
- انتخاب خودکار نقش و ایموجی با مدل (قاعدهٔ `roleRules` و `word.role` را از قبل پشتیبانی می‌کنیم).
- فونت متغیر با انیمیشن وزن، حرف‌به‌حرف برای لاتین، صدای افکت، متن پشت سوژه.
- صدور ویدیو در اپ با WebCodecs و Mediabunny.

## ۸. محدودیت‌های شناخته‌شده
- `glow` جدا نداریم؛ سایهٔ بدون جابه‌جایی همان کار را می‌کند.
- پشتیبانی Canvas در Safari و Firefox آزمایش نشده است.
- عددهای منطقهٔ امن راهنما هستند و باید با هر پلتفرم تطبیق داده شوند.
