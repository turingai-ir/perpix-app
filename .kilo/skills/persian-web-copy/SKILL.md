# Persian Website Copy

Write Persian for people, not a literal translation of English marketing copy. The reader should quickly understand what this product does, why it matters, and what action to take.

## Before Writing

Read the existing page, the product behavior, and the target destination of each CTA. Preserve factual claims, prices, feature names, limits, and legal conditions. Do not invent a discount, guarantee, popularity claim, or product capability.

Determine the current brand voice before changing its register:

- Use polite, friendly standard Persian by default.
- Use `تو` only when the surrounding product copy already uses it consistently.
- Use colloquial Persian only for a youthful or informal brand; keep it natural and restrained.
- Keep technical terms that users already recognize. Explain a term briefly when it affects a decision.

## Copy Rules

- Lead with the user's outcome, then explain the product mechanism if needed.
- Give each sentence one clear idea. Remove filler before shortening important conditions.
- Prefer concrete verbs and outcomes: `فایل‌هات را مرتب کن` instead of `مدیریت بهتری داشته باش`.
- Use familiar Persian phrasing rather than translated slogans.
- Match the CTA to its real next step: `دیدن نمونه‌ها`، `ساخت حساب`، `مقایسهٔ پلن‌ها`، `ادامهٔ پرداخت`.
- Avoid generic claims such as `تجربه‌ای بی‌نظیر`، `تحولی بزرگ`، `در دنیای امروز` and `بهترین انتخاب` unless evidence appears on the page.
- Do not call the user `کاربر` in published copy unless the interface specifically needs the technical meaning.

## Colloquial Persian

When an informal voice is appropriate, use modern spoken Persian without forced slang:

| Avoid | Prefer |
| --- | --- |
| هم‌اکنون اقدام نمایید | همین حالا شروع کن |
| امکان استفاده برای شما فراهم است | می‌تونی ازش استفاده کنی |
| در سریع‌ترین زمان ممکن | خیلی زود / سریع |
| نسبت به انجام عملیات اقدام کنید | انجامش بده |
| می‌باشد | است |

Do not overuse `خیلی`، `فوق‌العاده`، `راحت` or exclamation marks. A conversational tone must still be credible, readable, and consistent.

## Output By Scope

- For one phrase or CTA, return only the revised phrase unless alternatives are requested.
- For a component, preserve the existing text structure and return the revised strings in order.
- For a page, use a clear hierarchy: `H1`، supporting line, sections, benefits, proof, and CTA.
- When meaning is uncertain, use the least assumptive wording and state the material unknown briefly rather than publishing an invented claim.

## Final Check

- Is the value understandable without the English source?
- Does every claim have support in the product or current page?
- Does the tone match neighboring Persian text?
- Does each CTA name the actual action?
- Are punctuation, `ی` and `ک` Persian, and half-spaces used correctly?
