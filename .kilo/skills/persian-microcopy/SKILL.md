# Persian Product Microcopy

Write short text that helps a person complete the next action. State what happened, what is needed, and what can be done next. Never sacrifice clarity for a clever phrase.

## Buttons And Links

- Start with an action: `افزودن عکس`، `ذخیرهٔ تغییرات`، `دیدن جزئیات`.
- Make the action specific when the destination matters: `ادامهٔ پرداخت` is better than `ادامه`.
- Do not use `کلیک کنید` in button text.
- Keep labels brief; use a nearby description for conditions or consequences.

## Forms And Validation

- Name the field and explain the correction: `شمارهٔ موبایل را کامل وارد کن.`
- Do not blame the person: avoid `ورودی اشتباه است`.
- Do not use an error for information that can appear before submission.
- Keep formal/informal address aligned with the rest of the interface.

## Status Messages

| State | Pattern | Example |
| --- | --- | --- |
| Loading | Say what is loading | `در حال بارگذاری سفارش‌ها...` |
| Success | Confirm the completed action | `تغییرات ذخیره شد.` |
| Error | State the problem and recovery | `اتصال برقرار نشد. دوباره امتحان کن.` |
| Empty state | State what is absent and the next action | `هنوز پروژه‌ای نداری. اولین پروژه‌ات را بساز.` |
| Destructive action | State the irreversible result | `با حذف عکس، قابل‌بازیابی نیست.` |

## Voice And Safety

- Do not promise a result the system cannot verify.
- Do not hide payment, deletion, or permission consequences behind vague language.
- Use `تو` only when it is already the established product voice. Otherwise write polite neutral Persian: `دوباره تلاش کنید.`
- Avoid forced slang and excessive exclamation marks.

## Final Check

- Can a first-time visitor understand the next action without context?
- Does the message match the actual product state?
- Is the tone consistent with adjacent strings?
- Are Persian punctuation and half-spaces correct?
